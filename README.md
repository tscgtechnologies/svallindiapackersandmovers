## Features & Technology Stack
- **HTML5**: Semantic markup, accessible structure, Schema.org LocalBusiness JSON-LD, Open Graph tags.
- **CSS3**: Custom CSS system with CSS variables, mobile-first responsive layout, dark navy & warm orange color system, flexbox/grid layout, smooth keyframe animations.
- **Vanilla JavaScript**: Lightweight, modular JS with no external frameworks or libraries.
- **WhatsApp Integration**: Instant quotation form generation redirecting directly to WhatsApp with pre-filled details.
- **Real Work Gallery**: Includes 10 real uploaded photos of packed furniture, boxes, and transport vehicles with an accessible full-screen lightbox.
- **Accordion FAQ**: Interactive smooth-collapsing FAQ section.
- **Mobile First**: Fixed bottom action bar (`[ Call Now ] [ WhatsApp ]`) on mobile devices for conversion optimization.
